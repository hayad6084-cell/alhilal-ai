# تفعيل JSON2Video في الهلال AI

## ما الذي أضيف؟
- واجهة حديثة داخل صفحة **استوديو المونتاج** باسم JSON2Video Studio.
- إضافة عدة مشاهد، كل مشهد حتى 10 ثوانٍ في هذه الواجهة.
- نصوص/عناوين للمشاهد، وروابط HTTPS عامة لصور أو فيديوهات، مع اختيار مقاس 16:9 أو 9:16 أو 1:1.
- إرسال المشروع إلى JSON2Video ومتابعة حالة التصيير حتى يظهر رابط MP4.
- حفظ نتيجة الفيديو في مشاريع المستخدم، وإظهار حالة إعداد JSON2Video في فحص إعدادات السيرفر للمسؤول.
- مفتاح API يبقى على السيرفر ولا يُرسل إلى المتصفح.

## إعداد Render
من لوحة Render افتح الخدمة ثم **Environment** وأضف:

- `JSON2VIDEO_API_KEY` = مفتاح API من لوحة JSON2Video.
- `JSON2VIDEO_TEMPLATE_ID` = اختياري، معرّف قالب حقيقي من JSON2Video فقط إذا أردت استخدام قالب محفوظ. الواجهة الحالية ترسل مشاهد مباشرة، لذلك لا تحتاج المتغير الاختياري.

بعدها احفظ الإعدادات ثم أعد النشر (Deploy latest commit / Manual Deploy حسب إعداد مشروعك).

لا تضع المفتاح داخل `index.html` أو في رسالة عامة أو في GitHub. إذا انكشف المفتاح، ألغِه وأنشئ مفتاحًا جديدًا.

## رفع الملفات
استبدل ملفات المشروع الحالية بـ `server.mjs` و`index.html` الموجودين في هذا المجلد ضمن نسخة احتياطية أولًا، ثم ارفعها إلى المستودع/طريقة النشر المعتادة. لا تحذف بقية ملفات مشروعك أو إعدادات Firebase/Render. هذه الحزمة لا تنشر الموقع تلقائيًا.

## ملاحظات مهمة
- رابط الوسائط يجب أن يكون `https://` ويمكن لخوادم JSON2Video الوصول إليه. الملفات المحلية التي تختارها من الهاتف لا يتم رفعها إلى JSON2Video تلقائيًا في هذه النسخة.
- JSON2Video خدمة تركيب/تصيير فيديو، وليست بالضرورة مولّد صور أو فيديو من وصف نصي وحده؛ التوليد الإبداعي يحتاج مزود توليد منفصلًا.
- كل عملية تصيير تستخدم رصيد/حصة حساب JSON2Video لدى المزود، بالإضافة إلى خصم نقطة واحدة من نظام نقاط الهلال AI في هذا التكامل؛ راجع حصة مزودك قبل الاستخدام.
- هذه التعديلات لم تُنشر على موقعك الحي ولم تُختبر باستخدام مفتاح API حقيقي.
