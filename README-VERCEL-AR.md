# الهلال AI — نسخة متوافقة مبدئيًا مع Vercel

## الملفات
- `index.html`: واجهة الموقع الحالية كما هي.
- `api/[...path].mjs`: مدخل مسارات API على Vercel.
- `server-core.mjs`: منطق الخادم الأصلي بعد تحويله إلى handler بدل `listen()`.
- `package.json` و`vercel.json`: إعدادات النشر.

## النشر
1. فك ضغط الملف، ثم ارفع الملفات والمجلدات الموجودة مباشرةً بجوار هذا الملف إلى جذر مستودع GitHub (لا ترفع المجلد الخارجي كطبقة إضافية).
2. في Vercel اختر Import Project للمستودع، واترك Framework Preset على Other، وتأكد أن Root Directory هو `./`.
3. تأكد أن Root Directory هو `./`، ثم Deploy.
4. أضف متغيرات البيئة في Vercel Project → Settings → Environment Variables، ثم أعد Deploy.

## متغيرات Firebase المطلوبة للتخزين الدائم
- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY` (احتفظ به سرًا؛ أدخله في إعدادات Vercel فقط، مع تنسيق الأسطر الذي تقبله لوحة Vercel)

ولتشغيل تسجيل Google يلزم أيضًا:
- `FIREBASE_WEB_API_KEY`
- `FIREBASE_AUTH_DOMAIN`
- `FIREBASE_APP_ID`

متغيرات مزودي الذكاء الاصطناعي والإدارة التي تستخدمها في النسخة الأصلية يجب نقلها أيضًا إلى Vercel Environment Variables، مثل `GEMINI_API_KEY`, `LTX_API_KEY`, `APIFRAME_API_KEY`, `XKIRO_API_KEY`, `ADMIN_PHONE`, `ADMIN_INITIAL_PASSWORD`, و`SESSION_SECRET` حسب الخدمات التي تستخدمها.

## اختبارات بعد النشر
- افتح `/api/health` ويجب أن تظهر `persistentStorage:true` و`databaseConnected:true` بعد ضبط Firebase بنجاح.
- افتح `/api/config` للتحقق من حالة الإعدادات العامة.

## حدود يجب معرفتها قبل الاعتماد على الإنتاج
- Vercel Serverless لا يوفر نظام ملفات دائمًا؛ أي fallback إلى JSON أو ملفات داخل مجلد المشروع أو `/tmp` ليس قاعدة بيانات دائمة، وقد يختفي أو لا يكون مشتركًا بين النسخ.
- Firestore يحفظ بيانات الحسابات والسجلات التي يستخدمها الكود بالفعل عند تهيئته. لكن ملفات الفيديو المرفوعة حاليًا تُكتب إلى القرص المحلي؛ مسار رفع الفيديوهات/استرجاعها يحتاج نقلًا مستقلًا إلى Firebase Storage أو خدمة تخزين كائنات قبل الاعتماد عليه على Vercel.
- مهام التوليد التي يتم تتبعها في الذاكرة (مثل بعض job IDs) قد تفقد حالتها بين تشغيلات Serverless؛ يجب اختبارها، وقد تحتاج نقل حالة المهام إلى Firestore.
- حدود حجم الطلب والمهلة في Vercel تختلف حسب الخطة والإعداد؛ رفع فيديو كبير (حتى 1GB كما تسمح الواجهة) غير مضمون بهذه النسخة ولا ينبغي اعتباره جاهزًا على Vercel.
- الحسابان الموجودان في ملف Excel لم يتم استيرادهما تلقائيًا. لا تحذف ملف النسخة الاحتياطية ولا تستورد كلمات مرور مؤقتة كنص صريح. نحتاج خطوة استيراد آمنة ومراجعة التكرار قبل نقل الحسابات.

هذه نسخة تحويل أولية للحفاظ على الواجهة ومعظم API الحالية، وليست إثباتًا أن Firebase متصل أو أن جميع الميزات تم اختبارها في Vercel. لا تضع أي مفاتيح سرية في GitHub أو داخل `index.html`.
