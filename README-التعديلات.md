# الهلال AI — حزمة مراجعة وإصلاح

## الملفات الكاملة الموجودة في هذه الحزمة
- `index.html`: واجهة الموقع.
- `server.mjs`: خادم Node.js.
- `package.json`: الاعتماد المطلوب وأمر التشغيل.
- `render.yaml`: إعداد خدمة Render.

## الإصلاحات في هذه النسخة
1. إضافة اختيار صورة من الهاتف/الكمبيوتر في إدارة المتجر، مع معاينة وضغط الصورة تلقائيًا قبل الحفظ. يمكن أيضًا إدخال رابط صورة مباشر.
2. عند تعديل منتج دون اختيار صورة جديدة، يحافظ النموذج على صورته الحالية.
3. إظهار صور المنتجات في قائمة إدارة المتجر.
4. تعديل قراءة الحسابات لتجربة البحث في مخزن JSON القديم عند عدم وجود الحساب في Firestore، وترحيله إلى Firestore إذا عُثر عليه.
5. إضافة `package.json` و`render.yaml` لأنهما لم يكونا ضمن الحزمة السابقة.

## مهم جدًا بخصوص «الحساب غير موجود»
إذا كانت الحسابات محفوظة في مشروع Firebase قديم مختلف، فلن يستطيع الكود الوصول إليها من المشروع الجديد تلقائيًا. يلزم ربط السيرفر بمشروع Firebase الذي يحتوي على بيانات المستخدمين، أو نقل بيانات المستخدمين من المشروع القديم بطريقة آمنة. إصلاح القراءة الاحتياطية ينفع فقط إذا كانت ملفات JSON القديمة موجودة ضمن `DATA_DIR`/مجلد `data` الحالي. لا تحذف قاعدة البيانات القديمة أو بياناتها قبل التأكد من استرجاع الحسابات.

## متغيرات Render / Firebase
يجب ضبط `FIREBASE_PROJECT_ID` و`FIREBASE_CLIENT_EMAIL` و`FIREBASE_PRIVATE_KEY` في Environment إذا أردت استخدام Firestore. استخدم `SESSION_SECRET` ثابتًا وطويلًا لتجنب انتهاء صلاحية الجلسات بعد إعادة النشر. أضف مفاتيح مزودي الذكاء الاصطناعي بشكل منفصل حسب الخدمات التي تستخدمها. لا تضع المفاتيح السرية داخل `index.html` أو GitHub.

## التحقق الذي أُجري
تم فحص صياغة JavaScript في المتصفح والخادم باستخدام `node --check`. لم يُجرَ نشر فعلي على Render، ولم يمكن التحقق من قاعدة بيانات Firebase الحقيقية أو تسجيل دخول مستخدم حقيقي من هذه البيئة.
