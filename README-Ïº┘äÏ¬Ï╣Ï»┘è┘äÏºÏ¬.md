# الهلال AI — حزمة Vercel مراجعة

## الملفات
- `index.html`: واجهة الموقع، وتشمل رفع صورة المنتج من الهاتف/الكمبيوتر مع معاينة وضغط الصورة.
- `server.mjs`: مسارات API مع الحفاظ على تشغيله كسيرفر Node عادي.
- `api/[...path].js`: نقطة دخول API متوافقة مع Vercel Functions.
- `vercel.json`: توجيه طلبات الموقع وAPI.
- `package.json`: اعتماد Firebase Admin وأمر تشغيل Node.
- `render.yaml`: يبقى لتشغيل بديل على Render إن احتجت.

## قبل النشر على Vercel
1. ارفع كل الملفات والمجلد `api` إلى جذر مستودع GitHub، مع الحفاظ على المسارات كما هي.
2. من Vercel > Project > Settings > Environment Variables أضف متغيرات Firebase Admin التي تخص **المشروع الذي يحتوي حساباتك الحالية**:
   - `FIREBASE_PROJECT_ID`
   - `FIREBASE_CLIENT_EMAIL`
   - `FIREBASE_PRIVATE_KEY` (ضع المفتاح الخاص كاملًا، ويمكن أن تكون فواصل الأسطر `\\n`)
   - `SESSION_SECRET` قيمة عشوائية ثابتة وطويلة، ولا تغيّرها بين عمليات النشر.
3. إن كان تسجيل Google مستخدمًا، أضف أيضًا `FIREBASE_WEB_API_KEY` و`FIREBASE_AUTH_DOMAIN` و`FIREBASE_APP_ID`.
4. أعد النشر ثم افتح `/api/health` وتأكد أن `persistentStorage` تساوي `true`.

## تنبيهات مهمة
- لا تغيّر Firebase إلى مشروع جديد إذا كانت حساباتك القديمة في مشروع آخر؛ يجب ربط متغيرات السيرفر بالمشروع الذي يحتوي بيانات المستخدمين. لا ترسل المفاتيح السرية في المحادثة.
- حفظ المنتجات وصور المنتجات يحتاج إعداد Firestore صحيحًا؛ صور المنتجات تُضغط داخل المتصفح قبل الحفظ لتقليل الحجم.
- **رفع الفيديوهات الكبيرة لم يُفعّل على Vercel في هذه الحزمة**؛ لأن مسار الرفع القديم كان يحفظ على قرص محلي غير دائم، ما قد يؤدي لفقدان الفيديو. ستظهر رسالة واضحة بدل الادعاء بأن الملف حُفظ. استخدم زر واتساب مؤقتًا. لتفعيل الرفع الدائم يلزم ربط Firebase Storage وضبط صلاحياته ثم اختبار رفع ومراجعة الفيديو.
- أي وظائف تعتمد على ملفات JSON محلية لا تُعد تخزينًا دائمًا على Vercel. تأكد من أن بيانات الحسابات والمنتجات التي تحتاج استمرارًا موجودة في Firestore قبل الاعتماد على النشر.

## الاختبارات
تم فحص صياغة ملفات JavaScript باستخدام `node --check`. لا يمكن من هذه البيئة اختبار حساب Firebase الحقيقي أو التحقق من النشر على مشروع Vercel الخاص بك؛ لذلك اختبر تسجيل الدخول، حفظ منتج، ثم تحديث الصفحة قبل اعتبار الإصلاح نهائيًا.
